One other way to check the validity of these variables is to plot a simple scatter plot with the x-axis representing one variable and the y-axis representing the other.

In [41]:
# Scatter plot
### YOUR CODE HERE ###
sns.scatterplot(
    data= df, 
    x= 'driving_days', 
    y= 'activity_days'
    
)



plt.title('Scatter Plot of driving_days vs. activity_days')

plt.plot([0,31], [0,31], color='red', linestyle='--');

The scatter plot confirms our data is logical. activity_days acts as a ceiling for driving_days. Users frequently use the app without driving, but they never drive without the app recording activity.

Notice that there are absolutely no data points below the red line. This is the most critical insight from the graph, and it reveals a logical rule: $\text{activity_days} \geq \text{driving_days}$

A user cannot have more driving days than activity days. Why?

Because to log a "driving day" in the app, the user must have the app active.

You can open the app (count it as an active day) but choose not to drive. However, you cannot record a driving day without the app registering that you used it.

Notice that there is a theoretical limit. If you use the app to drive, then by definition it must count as a day-use as well. In other words, you cannot have more drive-days than activity-days. None of the samples in this data violate this rule, which is good.

def cap_upper_outliers(data, column, percentile=0.95):
    
    
    upper_limit = data[column].quantile(percentile)
    
    
    data[column] = data[column].clip(upper=upper_limit)
    
    
    print(f"{column:<25} | Percentile: {percentile:.2f} | Cutoff: {upper_limit:.2f}")
